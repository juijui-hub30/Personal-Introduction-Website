## Project Description
This project is a personal introduction website created using HTML and CSS.
The website introduces my background, education, skills, hobbies,
career goals, and contact information.
The purpose of this project is to demonstrate my understanding of
basic HTML and CSS concepts, including website structure, styling,
navigation, responsive design, and basic CSS animations.
## Features
- Personal introduction
- Profile picture
- About Me section
- Educational background
- School logos
- Skills section
- Hobbies and interests
- Career goals
- Contact information
- Navigation menu
- Responsive design
- CSS hover effects
- CSS profile picture animation
- Clean and organized layout
## Technologies Used
- HTML5
- CSS3
